# Eco Sense Bin – Smart Recycling Bin with Real-Time Feedback

## Project Overview

Eco Sense Bin is an IoT-inspired Smart Recycling Bin dashboard designed to improve waste management through real-time monitoring and analytics. The dashboard provides live insights into bin status, waste classification, fill levels, and environmental impact, helping optimize waste collection and encourage sustainable recycling practices.

---

## Features

- Real-time bin monitoring
- Waste classification dashboard
- Fill level tracking
- Sensor status monitoring
- Collection schedule management
- Environmental impact analytics
- Responsive web dashboard
- Modern user interface
